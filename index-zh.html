朱斌（Bin Benjamin Zhu），博士 · 北京雁栖湖应用数学研究院（BIMSA）教授

可信 AI、AI 安全与可信计算。

我曾在微软工作 24 年以上，其中 22 年在微软亚洲研究院（MSRA），3 年在 M365 BizChat / Copilot、Researcher agent 和微软 Bing Core Search 等产品团队；另有 4 年创业经历， 曾任多媒体水印公司 Cognicity 的联合创始人和主管科学家。我的研究覆盖可信 AI、AI 安全、 AI 在安全中的应用和可信计算；近期产品团队工作包括 Copilot AI 助手推理，以及微软 Bing Core Search 中 用于替代稀疏+稠密检索的新型多向量检索机制。此前和并行工作还包括隐私保护计算、认证、CAPTCHA、 Web 系统、多媒体安全和水印。

我推动多项研究成果转化到微软产品和服务，论文发表于安全、AI、系统和多媒体等重要会议和期刊， 并长期指导学生、建立跨微软亚洲研究院（MSRA）、微软产品团队和高校合作伙伴的合作。 在 Cognicity 期间，我也参与推动多媒体水印技术商业化。

我也共同指导学生科研，包括自 2018 年起与华中科技大学合作， 以及自 2025 年起与上海交通大学合作。我共同指导的 4 名博士生已毕业；其中 3 名在中国高校任助理教授， 包括 1 名在上海交通大学，另有 1 名加入中国主要科技公司任研究员。

精选亮点

Copilot 与微软 Bing Core Search

负责面向产品的应用研究，覆盖 M365 BizChat / Copilot、Researcher agent 和微软 Bing Core Search，包括 AI 助手推理、深度搜索、评估/回放基础设施、提示词优化、文档理解，以及用于替代稀疏+稠密检索的多向量检索机制。

AI 安全研究

微软产品转化

推动研究成果转化到微软产品和服务，包括人工操作勒索攻击防御、恶意 PowerShell/脚本检测、钓鱼与欺诈检测、CAPTCHA、Bing 索引压缩和移动完整性检测。

可信计算基础

长期开展隐私保护计算、用户认证、CAPTCHA、Web 系统、多媒体安全、水印、内容保护和 DRM 等方向研究，将安全研究与实际部署需求相连接。
