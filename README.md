# binzhu.github.io

Static output for Bin Zhu's personal GitHub Pages site.

## Local Preview

Use any static web server from this folder. For example, with Node.js:

```powershell
npx --yes serve -l 8000 .
```

Then open `http://localhost:8000/`.

The publication, patent, and experience pages are generated from private source files in the resume project. Raw archive data is intentionally not stored in this public repository.
